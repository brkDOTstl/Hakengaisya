# Public reference and model details

The public benchmark snapshot is display-only and lives in `fixtures/public-benchmarks.json`. It was checked on 2026-10-10 against first-party release/model pages. The coarse assessment is an AI-written interpretation of those reports, not a new evaluation run or an independent validation of vendor results.

Source pages:

- [OpenAI: GPT-6 Astra](https://openai.com/index/gpt-6-astra/)
- [Anthropic: Sonnet 5.5, including the Opus 5.5 comparison](https://www.anthropic.com/claude-sonnet-5-5)
- [Anthropic: Fable 5.1 and Mythos 5.1](https://www.anthropic.com/claude-fable-and-mythos-5-1)
- [Anthropic: Haiku 5.5](https://www.anthropic.com/claude-haiku-5-5)
- [SpaceXAI: Grok 4.7](https://x.ai/news/grok-4-7)
- [Meta: Muse Spark model card](https://dev.meta.ai/models/muse-spark)

Results retain the benchmark's original scale, version, and relevant settings. Terminal-Bench 2.1 and 4.0, CursorBench 3.2.0 and 4.0, and different reasoning efforts are not interchangeable. Public figures do not enter reviewer credibility, local D1-D6 scores, or dispatch recommendations.

Clicking a model opens its selected evidence layer, route, effort, task type, and difficulty. The detail view includes de-identified comments, examples, skill guidance, score-support labels, and a six-axis local radar. Multiple unrelated contexts are not merged by the detail API. Missing dimensions have no plotted point; a measured zero is a point at the center.

The D1-D6 guide is placed beside the ranking on wide screens and below it on smaller screens. The radar uses the same dimension definitions. Public reference results are shown in a separate detail panel, including their source and check date, even when no local scores exist.

The snapshot is not automatically refreshed. A later update should check the linked sources, preserve changed versions/conditions, and record a new check date. No private workspace files or local evidence paths are distributed with this snapshot.
